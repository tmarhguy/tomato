# Tomato engineering journal

> **Historical record:** Entries in this directory preserve the design as it
> was discussed on their publication date. They are not canonical current
> documentation. Some describe superseded word widths, register designs, ISA
> counts, software versions, or preview-only behavior. Use
> [`../status.md`](../status.md) for present facts and
> [`../documentation-policy.md`](../documentation-policy.md) when claims differ.

The journal records the path from early datapath experiments through the
discrete ALU slice, FPGA Tomato, Tomato OS, and later integrations. Historical
content is intentionally not rewritten.
