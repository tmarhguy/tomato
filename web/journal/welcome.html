Welcome to Tomato 32

A build log for the questions that come up and the answers settled for — from simple gates to a parametric datapath.

Tyrone Marhguy · the vault opens

This is a build log for Tomato 32. It keeps track of the questions that come up and the answers settled for. It is focused on constraints explored and the journey from building simple logic gates to a parametric datapath — a machine where an ISA is a map onto muxes, not a second computer in copper.

If you are reading this, you probably love building computers and enjoy the architecture like I do. Enjoy.

Everything after this page is an argument written down: word width, decode fanout, the ALU that ate the muxes, the multiply that would not wait thirty-two cycles, the day the boards were ordered. Each file below is the dispatch in docs/log/; the shield opens the typeset page on tomato.tmarhguy.com.
