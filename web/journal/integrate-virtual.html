Dispatch · Virtual Tomato

Do Not Discard the Preview

The development preview becomes a browser journey built from the generated OS image.

15 September 2026 · from the historical log

Historical entry: this page records the project at the time. Current facts and execution labels follow the status page.

The preview solved a local iteration problem. Integrating it into the website made the same OS menu, games, and Envelop demo available without requiring an FPGA or installation.

Virtual Tomato executes the generated OS image and burned control tables in a functional ISA-level emulator. It models behavior, not cycle timing. The demo phone is local and simulated; it is not the Envelop backend, radio path, or physical Tomato.

The distinction is deliberate: browser-emulator regression proves the software path, while FPGA demonstrations and live bridge evidence establish different claims.
