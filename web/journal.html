Register Upgrade

32,768 General Purpose Register File — 15-bit AS6C62256 depth. Half a Blackwell SM's physical register file. Using less would waste the chips.

Dispatch · Register file · open the full entry

Tomato exposes 32,768 32-bit GPR locations because the discrete SRAMs already provide fifteen address bits. The chips, buses, and mirrored 3R1W structure are already there — anything less leaves usable depth disconnected.
