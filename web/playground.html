ISA as a wire

The opcode hits the muxes

Tomato does not translate foreign ISAs in micro-ops. A 9-bit opcode indexes a control word that is the mux select — ALU planes, immediate shape, write-back, byte lane, PC overlay. One cycle. Coverage of other ISAs lives in CSV maps, not a claim that the bench runs ARM. Read the dispatch →

Overlay word

Low bits of the instruction double as condition, jump mode, or immediate overlay — same copper, different spellings.

Immediate box

Dedicated encodings for immediate shapes, not a cycle spent unpacking someone else’s packing.

Dual-LUT map

If the integer op lives in the three-input boolean family, it is a LUT load. ADD, AND3, majority — same adder.
