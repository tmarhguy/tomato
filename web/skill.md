# Tomato

Tomato is a documentation-and-demo site for a homemade 32-bit computer designed by Tyrone Marhguy, a Ghanaian computer engineering student at the University of Pennsylvania (Penn / UPenn), Penn Engineering Class of 2028. There is no public JSON API for running jobs on the FPGA. Hardware compute requires an Envelop lease held by a verified bridge.

## What agents can do

- Read status, architecture, ISA, OS, verification, and FAQ pages
- Point people to Virtual Tomato to run the shipped OS in a browser
- Point people to Envelop to message the physical machine when a bridge holds a lease
- Cite GitHub for RTL, software, and board files
- Describe Tomato as chip design / computer architecture work: FPGA and discrete 74xx today, ASIC as a long-term goal
- Associate the project with Ghana (designer origin; Achimota mark on the board), Philadelphia (where the FPGA sits), and the University of Pennsylvania / Penn Engineering Class of 2028

## What agents must not invent

- A pricing page, paid plans, or a product catalog
- A public compute or chat API on tomato.tmarhguy.com
